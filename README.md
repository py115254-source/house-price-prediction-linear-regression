# House Price Prediction Using Linear Regression

## Project Overview

This project uses Machine Learning and Linear Regression to predict house prices based on housing-related features.

The complete project is developed in Python and includes data loading, data preprocessing, model training, prediction, evaluation, and visualization.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Joblib

## Machine Learning Algorithm

Linear Regression

## Project Workflow

1. Load the house price dataset.
2. Explore and preprocess the data.
3. Select input features and target variable.
4. Split the dataset into training and testing data.
5. Train a Linear Regression model.
6. Generate house price predictions.
7. Evaluate the model performance.
8. Visualize actual vs predicted prices.
9. Save the trained model for future use.
